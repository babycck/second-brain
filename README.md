# 第二大脑 · 故事资产与认知工坊 (Second Brain)

> 基于 FastAPI 与原生现代化 Web UI 构建的故事资产解构库、原生日记随笔、多专家头脑风暴与灵感炼金系统。

---

## 🌟 核心特性

1. **万能素材捕获与工业级拆解**：
   - 随记长文提炼、名著逆向拆解、影视镜头逆向分析
   - 6 大预设维度爆破（人物档案、关系图谱、剧情结构、伏笔链路、底层世界观、写作手法）
   - 全文长本文档（.txt / .md）一键导入与原子化立卡

2. **原生随笔与日记（免分析直存）**：
   - 零网络等待、无需模型分析，100% 原汁原味毫秒级本地留存
   - 沉淀后可一键注入头脑风暴或作为灵感炼金核心骨架

3. **头脑风暴会客室**：
   - 商业编剧、战略操盘手、社会心理学者、荒诞派哲人 4 席专家联席交锋激辩
   - 支持一键调入任意日记/已沉淀资产作为风暴议题
   - 精彩观点一键沉淀入库

4. **灵感炼金机**：
   - 从干净资产中调取骨架与原料，碰撞推演出小说大纲、60 秒短剧分镜、因果链或金句
   - 支持炼金产物一键回流入库，形成自增生飞轮

5. **全平台与手机端支持**：
   - 响应式设计，完美适配 iPhone / iPad / 移动端浏览器
   - 支持 iOS Safari「添加到主屏幕」作为全屏独立 App 使用

---

## 🚀 本地快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务 (默认端口 8899)
python app.py
```

浏览器打开 `http://127.0.0.1:8899` 即可访问。
